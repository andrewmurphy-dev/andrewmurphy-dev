### Architecture mindset

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌──────────────┐
│   Ingest    │ ──▶ │  Transform   │ ──▶ │   Serve     │ ──▶ │   Observe    │
│  files · DB  │     │ validate · ETL│     │  REST · CLI │     │ logs · metrics│
└─────────────┘     └──────────────┘     └─────────────┘     └──────────────┘
```

*The same pipeline thinking applies whether I'm building a POS API, a housing data service, or an ML experiment.*
